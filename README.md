# 衣柜小程序 · 1.3.0

衣柜是一款面向服装店的微信进销存与记账小程序，管理商品、颜色尺码库存、进货、销售、客户欠款和小票。2026-09-14 统一产品名称；业务修复记录见测试报告。

本仓库根目录直接存放可导入的源码，也可下载 [衣柜小程序测试修复版源码 ZIP](衣柜小程序-测试修复版-20260914.zip)。操作验证记录见 [全流程测试报告](docs/20260913-VSCode全流程测试.md)。

## 文件与功能导航

| 目录/文件 | 功能 |

| `app.js`、`app.json` | 小程序启动、页面注册、全局外观与本地运行模式 |

名称兼容说明：界面与工程名已改为“衣柜”。历史账本键、备份格式、AppID 保持兼容，用户自行填写的店名仍按原值显示；这些内容不应通过全局替换改写。旧测试报告保留当时的原始文件名称作为追溯依据。

**当前运行方式为本地模式：`app.js` 中 `useLocal=true`。** 数据通过 `App.dataCloud` 和 LocalCloud 保存到当前设备，不需要创建云环境。`cloudfunctions/` 是原包保留的旧实现，尚未适配当前商品保存、原子存储及恢复流程；不能直接切换 `useLocal` 或照旧版说明上传云函数使用。本轮没有云部署或发布。

3. 本轮实际验证的调试基础库为 **3.17.3**。本机 2.33.0 的桌面 Canvas 组件报错并导致小票空白；切换后的 3.17.3 已显示正常小票。开发者工具提示 3.17.3 为灰度版本，正式营业前仍需在目标手机上验证。

## 已支持的营业流程

- 商品与颜色尺码独立库存；零库存商品可补货，进货按加权平均计算成本。
- 销售数量、手工单价、折扣、抹零、实收、找零和欠款；支付方式只记录账务，不实际发起微信支付。
- 客户和供应商档案、订单流水、整单退货、欠款补齐、统计和对账。
- 电子小票、蓝牙打印入口、备份导出、合并、覆盖恢复与恢复前备份。
- 重复请求去重、提交期间禁止修改、恢复账本后清除旧订单表单并阻止旧回调回填。

模拟器和手机分别保存本地账本，不自动同步。换设备或覆盖恢复前先导出备份。选择客户、商品规格后返回会保留当前页面输入；退出未提交页面或重启应用不保证保留草稿。

## 在 VS Code 测试

打开本项目文件夹，按 `Command+Shift+B` 运行“小程序：完整自动化检查”，或在终端输入 `npm run test:full`。任务依次执行全部回归测试和微信编译检查，遇到失败会停止并返回失败状态。任务输出会保存在 `artifacts/vscode-test-results.txt`。

这台 Mac 已安装官方 Node.js 24 LTS 到用户目录 `~/.local`；项目的终端配置已加入对应路径。换电脑时需自行安装 Node.js 18 及以上版本。VS Code 运行逻辑与模板测试；真实页面点击、软键盘、扫码和蓝牙等仍需微信开发者工具或真机测试。
